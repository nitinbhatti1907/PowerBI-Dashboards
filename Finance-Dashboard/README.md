# 💰 Finance Dashboard (Power BI)

## 📌 Overview
An interactive personal finance tracker built in **Power BI** to analyze income, expenses, savings, and EMI payments.  
The dashboard provides both **all-time insights** and **last-month analysis**, helping track spending behavior and financial planning with clarity.  

---

## 🔑 Key Features
- 📊 **All-Time vs Last-Month KPIs** (Income, Expense, Savings, Net Cash)  
- 💸 **Expense % vs Savings %** breakdown  
- 📈 **Net Cash Flow** analysis  
- 🏷️ **Category-wise expense visualization**  
- 🔄 Connected with **Google Sheets** for live data updates  
- ⚡ Custom **DAX measures** for robust calculations

## 🛠️ Tools Used
- **Power BI Desktop** – for dashboard creation  
- **Google Sheets** – as the live data source  
- **DAX (Data Analysis Expressions)** – for measures and time intelligence  

---

## 🚀 Outcome
This dashboard enabled:  
- Clear visibility into **spending vs savings patterns**  
- Tracking of **monthly EMI impact** on cash flow  
- Insights for **personal financial planning** and **budget optimization**  
- Seamless refresh and automation via Power BI Service  

---

## 📂 How to Use
1. Clone/download this repo.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. Connect your own Google Sheet or dataset to refresh the visuals.

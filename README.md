# 📊 Power BI Dashboards

This repository contains interactive dashboards built using **Power BI**, showcasing data modeling, DAX, and visualization skills.  
Each dashboard is structured with its own `.pbix` file, dataset (where applicable), screenshots, and documentation.  

---

## 🔹 Dashboards

### 💰 [Finance Dashboard](./Finance-Dashboard)
- Personal finance tracker analyzing **income, expenses, savings, and EMI payments**.  
- Includes **All-Time vs Last-Month KPIs**, expense breakdown, and net cash flow analysis.  
- Data sourced from **Google Sheets** (CSV copy provided).  

---

### 📈 [Sales Insights Dashboard](./Sales-Insights-Dashboard)
- Sales performance dashboard analyzing **revenue and quantity by region, customers, and products**.  
- Features **Top 5 Customers & Products**, sales trend over time, and drill-down filters.  
- Data prepared using **SQL** and loaded into Power BI.  

---

## 🛠️ Tools & Skills Highlighted
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Data Modeling & Transformation  
- Integration with Google Sheets and SQL  
- Business Intelligence & Data Storytelling

## 🚀 How to Use
1. Clone/download this repository.  
2. Open the `.pbix` files in **Power BI Desktop**.  
3. Connect to the included dataset (CSV/Google Sheet/SQL) if refresh is required.

# 📊 Power BI Dashboards

This repository contains interactive dashboards built using **Power BI**, showcasing data modeling, DAX, SQL, and visualization skills.  
Each dashboard is organized as a portfolio-ready case study with its own report files, datasets where applicable, analysis, and documentation.

---

## 🔹 Dashboards

### 💰 [Finance Dashboard](./Finance-Dashboard)
- Personal finance tracker analyzing **income, expenses, savings, and EMI payments**.
- Includes **All-Time vs Last-Month KPIs**, expense breakdown, and net cash flow analysis.
- Data sourced from **Google Sheets** (CSV copy provided).

---

### 📈 [Sales Insights Dashboard](./Sales-Insight-Dashboard)
- Sales performance dashboard analyzing **revenue and quantity by region, customers, and products**.
- Features **Top 5 Customers & Products**, sales trends over time, and drill-down filters.
- Data prepared using **SQL** and loaded into Power BI.

---

### 🍕 [Pizza Sales Analysis](./Pizza-Sales-Analysis)
- End-to-end **SQL Server + Power BI** sales analytics project.
- Analyzes **revenue, average order value, order trends, pizza category/size mix, and product performance**.
- Includes **Top 5 / Bottom 5 pizzas** by revenue, quantity, and total orders.
- Uses SQL analysis to validate Power BI KPIs and business logic.
- Verified project KPIs include **$817.86K revenue**, **21,350 orders**, and **49,574 pizzas sold**.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the relevant `.pbix` file in **Power BI Desktop**.
3. Connect to the included dataset or source system if a refresh is required.
4. Review each project's README for its specific setup, analysis, and business questions.
